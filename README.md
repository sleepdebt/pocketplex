# PocketPlex

A lightweight, text-first Plex client for Linux retro handhelds. It streams from your own Plex Media Server over home Wi-Fi.

- **Primary target:** Anbernic RG35XX SP (H700)
- **Secondary target:** Miyoo Mini Plus (music-first)
- **Approach:** the server transcodes everything to 480p H.264, and the handheld shows a text menu and launches a player

Status: pre-alpha, Phase 0. See [`the spec`](the spec) for the spec and [`the docs`](the docs) for the multi-agent workflow.
